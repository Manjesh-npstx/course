Day 6 Assignment: Polish, Edge Cases, Error Handling & Presentation-Ready Cleanup
Objective: Treat today as a quality pass — handle edge cases, clean up the code and make the project ready to present tomorrow. No new features today, focus entirely on stability and polish.
Requirements:
Edge Case Testing — go through every form and action and test edge cases: empty submissions, invalid inputs, very long text, special characters, duplicate entries, expired/invalid token, network failure, etc. Fix anything that breaks.
Error Handling Review — make sure every API call has proper try/catch with meaningful error messages shown to the user (no raw error objects, no silent failures, no app crashes).
Loading & Empty States Check — revisit every page/list and confirm loading, error and empty states are handled consistently across the app, not just on the main pages.
Responsive Check — test the app on different screen sizes (mobile, tablet, desktop) and fix any obvious layout breaks.
Code Cleanup —
Remove console.logs, unused code, commented-out code, unused imports.
Make sure naming is consistent (components, files, variables).
Make sure there's no duplicate logic left anywhere (forms, API calls, validation).
README Update — update your project's README with setup steps, environment variables needed, test login credentials and a short description of what the app does.
